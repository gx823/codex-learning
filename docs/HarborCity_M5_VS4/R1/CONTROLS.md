# VS4 R1 操作规则

以下为本轮实现规则。Repair 1 新独立包 A6 已通过 189 项、0 FAIL；旧包失败保留在历史报告。其他专项及用户观感验收单列，不能将设计时长或规则表等同于全部验收；具体实测见 TEST_REPORT.md。

Shift 按住冲刺，攻击不清除冲刺意图。Q/滚轮循环、B 武器库、V 视角、P 暂停、T/H、F5/F9、空格跳跃/飞行上升均保留。Esc 是本轮自动化桌面操作的停止键，不代替 P。

## 星弓

- 左键按住拉弓，0.8 s 满弓；继续按住播放 Draw.Idle 循环。
- 松左键发射原 Exouch 箭。满弓散布 0；未满弓使用原战斗散布值，并显示按实际 FOV 投影的散布圈。伤害 34 / 54.4、速度 5000 cm/s、射程 6000 cm 不变。
- R 取消当前拉弓，不射出。菜单和切换也取消；切走播放 Unequip。
- 非冲刺放箭后，Release 前段 0.13 s 接 2 倍速 ReloadFromRelease，设计间隔约 0.547 s；搭箭完成前不能重新拉弓。最终两视角正常录像共六段 Release 到装填结束的状态间隔为 0.5391-0.5693 s；这是采样状态间隔，不是 OS 输入延迟。
- 冲刺放箭后保持空弦；松 Shift 自动 ReloadFromEmpty。空弦按左键先上箭再拉弓，期间按 R6 规则限速 400 cm/s，不清除 Shift 请求。
- Equip / Equip.Empty / Unequip 最大 2 倍速。切走时拉弓取消段最多 0.04 s，然后 Unequip；总时长目标 <= 0.6 s。正常录像中 Equip/Equip.Empty 最大 0.5306 s，Unequip 最大 0.5418 s；取消与系统输入到切换的端到端时长未单独量化，不能据此宣称全部切换延迟通过。
- 仅星弓的第一人称图元 FOV 为 95 度，ADS 时仍 95 度，FirstPersonScale 0.65；切走恢复原 75 度。世界 FOV、ADS 1.6 倍和输入补偿 0.625 不变。
- 旧 16:26 EXE 仍为 4 度。Repair 1 新 EXE 为获准的 6 度整体上限，保持约 0.1 s 平滑；A6 实际最大修正角 5.537234 度。保留作者横握角度，不额外倾斜。
- 当前平移为 0 cm。遮挡以准星中央 192 x 108 px 方框为门槛（手、袖子、弦不得进入；箭可进入），新 EXE 实测为 0 px，整条竖带 2,194 px 仅参考。仅新方框失败时才启用用户有条件允许的 <=2 cm 整体平移，并在放箭后 0.2 s 内回位；本候选未启用。原作对照关闭旋转修正和平移。

## 保留的 R6 规则

| 状态 | 实现值 |
|---|---|
| 冲刺轻剑 / 拳 | 552.5 cm/s，窗口结束恢复 650 |
| 冲刺腰射 | 650；普通点击 0.12 s 蓄力宽限不减速 |
| 冲刺 ADS / 星弓拉弓 | 400；结束后仍按 Shift 自动恢复 |
| 冲刺施法 / 装弹 | 400；动作后仍按 Shift 自动恢复 |
| 剑 / 魔导枪长按蓄力 | 宽限之后 200，松手后正常加速 |
| 跳跃 / 空中出招 | 保留冲刺请求；非冲刺 R5 规则不变 |

菜单、失焦、上下车和飞行模式切换仍释放输入。魔导枪蓄力光箭独立保留原 ReleaseBow 分支与 SpellFX Kind 6/7，原 0.28 s 间隔不受星弓状态机影响。C1 只修改冲刺速度判断：动画 elapsed 为 -1 时按窗口结束处理，连段、伤害与命中窗口代码不变。新 EXE 整组十会话 320/0；FP/TP 拳窗口恢复最大 0.05000/0.05001 s，冲刺意图全程保留。移动夹具的动态命中数另见报告，不等同于静止靶全命中。

P 菜单加入“新王都预览 / 返回港町”。预览是 B1 白模，旧港町仍默认；进入前使用原存档校验路径生成内存快照，不覆盖磁盘存档。预览禁用 F5/F9，返回后恢复临时进度。最终独立包三阶段接口测试 12 项、0 失败；真实菜单键鼠与旧进阶存档人工复测仍待用户。回程恢复未成功时保留快照并提示 F9，成功恢复前不要退出进程。

# 当前执行方式

用户恢复执行，画面质量要求不变，替换此前“不以节省 token、上下文、运行时间为目标”。

- 不启用子代理；素材、许可、参考研究由主线程顺序进行。
- 自审先看缩略拼图，必要时裁原图局部；交付审阅页保留原图。
- 日志仅取相关片段；正文只写结论、问题和图片路径，细节放 JSON 附录。
- 每个改动验证一次，失败才重试；只跑相关测试，第二阶段门和最终交付前各做一次完整回归。
- 长任务等待结束后读结果，不频繁轮询。
- 同一问题连续三次无进展，记录卡点和备选，转做其他工作，在阶段门报告。

Esc 立即停止桌面控制，游戏暂停用 P。仍不扩图、不删除旧候选、素材或存档。

A. 冲刺中出招不退出冲刺（最优先）

1. 先列出所有会清除冲刺状态、或把速度压到跑速以下的调用点（文件、函数、触发条件），包括开枪、瞄准、装弹、切武器。
2. 规则（数值是本轮建议默认值，可微调，写明最终值）：
   - 冲刺状态只由冲刺键决定。出招、开枪、施法、拉弓都不清除冲刺状态，结束后不需要重新按键。
   - 冲刺中挥剑、出拳：上半身出招，速度不低于冲刺速度的 85%（约 550 cm/s）；命中窗口结束后 0.2 s 内回到满冲刺速度。
   - 冲刺中腰射：保持满冲刺速度，上半身持枪射击；射速和散布规则不变。
   - 冲刺中按右键瞄准（ADS）或拉弓：瞄准期间降到跑速；松开右键时如果冲刺键仍按着，0.2 s 内自动回到冲刺。
   - 冲刺中施法、装弹：动作期间可以降到跑速，动作一结束自动回到冲刺。
   - 冲刺中按住蓄力：蓄力期间速度沿用 R5（约 200 cm/s）；松手出招后自动回到冲刺。
   - 跳跃和空中出招不改变落地后的冲刺状态。
   - 冲刺键是按住还是切换，沿用现在的设计，写进 CONTROLS.md。
3. 动作：冲刺前倾时上半身出招要协调，剑和手不能穿过自己的腿和头发；裙摆不能翻起。

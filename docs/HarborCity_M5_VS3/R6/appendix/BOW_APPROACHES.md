# 星弓三种画面方案

这不是三次相同指标复用。原始截图、运行结果与错误日志本地保留。

|方案|具体区别|实际观察|
|---|---|---|
|1 原动作直接重定向、左右手原样|Exouch 原生 FK、Ventyra 原生弓动画|源包实际左手拉弦，不符合右手拉弦；TP OwnerNoSee 设置错误，弓在主视口不可见；旧试射机位墙体遮挡，未命中。|
|2 UE 原生镜像、左手锚定展示网格|原生镜像表换右手拉弦，弦段按右手位置伸展，移动到空旷射线|两视角各 1/1 命中；肩部截面进入画面、手臂过大，源文件叫 Arrow 的网格误为第二弓体。|
|3 肩部按眼睛锚点归位、双骨 IK 贴合|仍使用购买动作，保留手腕/手指姿态和骨长；独立三维箭替换误命名弓体；在同一方案内调握把与拉弦目标坐标|预检两视角各 1/1；双手可见，配对遮挡 17.3127%，噪声 0.1106%。此后最后调整箭尖取景坐标，最终以 Shipping 验收数据为准。|

第三方案最终构图尚须用户审阅，数值通过不能代替双手握姿、原作色彩与动作观感认可。没有开展第四套动画/资产方案。

# R6 操作规则

Shift 沿用按住冲刺，松开停止；攻击中也可按下 Shift。Q/滚轮、B、V、P、T、H、F5/F9 以及视角增益沿用原设计。

|状态|R6 实现值|
|---|---|
|冲刺轻剑 / 拳|552.5 cm/s，即 650 的 85%；正常窗口结束后恢复 650|
|冲刺腰射|650；普通点击的 0.12 秒蓄力宽限不减速|
|冲刺 ADS / 星弓拉弓|400；结束后仍按 Shift 自动恢复|
|冲刺施法 / 装弹|400；动作后仍按 Shift 自动恢复|
|剑 / 魔导枪长按蓄力|宽限之后 200；松手后正常加速|
|跳跃 / 空中出招|保留冲刺请求；非冲刺 R5 跑跳规则不变|

菜单、失焦输入清空、上下车和飞行模式切换仍释放输入；不是出招清除。伤害、窗口、射程、散布、魔力、冷却未改。

最终包双视角每类十次的速度和命中见 TEST_REPORT。重要已知缺陷：TP 拳命中后旧动画停止逻辑与限速判断相互影响，窗口关闭后最差 0.733 s 才恢复，仍超过 0.2 s。其余最终收招恢复约 0--0.134 s；不能将收招值替代所有窗口值。源调用点全集见 appendix/SPRINT_CALL_AUDIT.md。

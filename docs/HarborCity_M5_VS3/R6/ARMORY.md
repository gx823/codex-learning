# R6 星弓

远程槽恢复 `Starbow`，武器库使用 Ventyra 原模型与银白淡蓝贴图，预览可旋转、缩放和装备，详情列出两个购买包的作者、Fab 地址及个人许可。

- 右键 ADS；左键按住拉弓，松开放箭；约 0.8 秒满蓄力。
- 普通箭伤害 34，满蓄力 54.4，速度 5000 cm/s，射程 6000 cm；沿用 R3。魔导枪的蓄力光箭保留。
- 原生 Ventyra 15 个变形骨骼，UE 另有导入根骨骼；原包五段弓动作均接入，快速松手用 Full_Action 的释放区段。
- 第三人称使用已授权 Mixamo Pro Longbow，经既有 R1 原生 IK 重定向到 Selestia，保留移动时上半身层。
- 第一人称使用 Exouch FBX 原动作重定向到现有 1.25 倍主角手臂。源动作左手拉弦，通过 UE 原生镜像表改成右手拉弦，再用双骨 IK 贴合握把与拉弦点，不替换人物网格或拉长手臂。
- 源包实际包含 27 个动作 FBX 和一个参考角色 FBX。源 Draw_Idle 与拉满末姿态不连续，因此保持 Draw 的末姿态作为满弓手部保持；弓仍使用自己的 Hold_Loop。
- 源工程名为 Arrow 的对象实际为另一弓体，不作为箭使用。显示箭是本轮创建的独立三维箭杆、箭头和尾羽，不承担伤害判定。

原 R3 自建弓与旧目录保留。新增导入、动画与派生资产均不公开；这里只发布行为、来源和测试记录。

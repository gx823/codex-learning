# 四把武器与造型收尾

R3 可装备目录仍为星潮剑、绯夜剑、魔导枪、蒸汽铳；八套蒸汽铳涂装保留。旧候选、源资产与用户存档保留。

两把剑接入原作者 2K BaseColor、Normal、Metallic、Roughness、Emissive；星潮护手宝石局部蓝光、出招／蓄力刻纹发光，绯夜暗底红光。原文件未修改。卡通描边与各角度材质观感仍 USER_REVIEW。

魔导枪在 Blender 5.2.2 中移除外露软管、瓶体等部件，加入有切面的蓝晶核和三个带符文的环；保留原 UV 与贴图明暗，再混合象牙色／淡金。最终实机偏深的金属和木纹是否符合目标需用户判断。

预览使用柔和渐变、主光和轮廓光；与游戏共用材质。四把预览占区高度像素估算分别为 70.1%、69.6%、72.8%、72.8%，绯夜在“约 70%”边界。取景为默认 3/4 角度。算法按预览内背景中值分离，非手工美术验收。

星弓模型、三视图与 6 段 pelvis+FK 动作已保存本地；三轮姿态方案依次发现持弓侧向、第一人称全身遮挡、手臂／握持仍不合格。依 REQUEST E.7 撤出可装备目录，Arrow 转为魔导枪蓄力射击。详见 CONTROLS。

真实鼠标点击仍 NOT_RUN。Steamlock 指尖／弹匣细节以最终近景与装弹录像供审阅；单帧和运行断言不能证明整个装弹动作零穿模。

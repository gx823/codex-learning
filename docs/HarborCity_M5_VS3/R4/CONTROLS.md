# R3 操作

- B 打开武器库，也可从 P 菜单进入；B 或关闭按钮退出。分页、拖转、缩放、涂装、试招、装备沿用 R2。
- Q／滚轮：空手 → 剑 → 当前远程槽。四把可装备武器：星潮剑、绯夜剑、魔导枪、蒸汽铳。F5/F9 保存／读取装备与涂装，须站稳。
- 剑：左键三段连击；按住蓄力、松开重击。蓄满发射约 8 m、宽约 1.8 m 剑气；原伤害、冷却和去重规则保持。
- 魔导枪：短按左键在松开时普通射击，伤害 34；按住约 0.8 s 后松开射出蓄力光箭，伤害 54.4、2 m 范围、约 50 m/s、最大约 60 m。两者都消耗一发弹药，R 装弹有效。普通射击因需判断蓄力，发射时机改为松开。
- 蒸汽铳：原射击、八套涂装和 R 装弹操作保持。
- 右键 ADS：放大 1.6／输入补偿 0.625。1/2 选择魔法目标后按住并松开左键发射；3 治疗，4 护盾持续 6 s。魔力、自然回蓝、冷却不变。
- V 切视角，P 暂停，T 切时段，H 帮助；步行／飞行环视增益 1.5，驾驶 1.125，驾驶 A/D 增益维持 M4-V1 两倍。飞行、翅膀和体力规则不变。

星弓经过三种姿态做法仍未通过第一人称握持验收，按 REQUEST E.7 暂不上线。光箭是魔导枪降级方案，不能把它称作星弓或宣称星弓存读档、拉弦手感通过。

自动测试中 Esc 立即停止当前操作链；游戏内暂停使用 P。交付完成后不继续桌面操作。


R4：冻结操作及全部数值沿用；星弓限定三种方案未过关，正式武器库仍四把，魔导枪蓄力光箭保留。造型与特效以当前R4审阅页为准。

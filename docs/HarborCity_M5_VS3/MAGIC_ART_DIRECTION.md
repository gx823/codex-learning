# 魔法阵定点改造

旧版只有轮廓环与基础符号，用户判定不够精美。新版使用三层独立阵纹：外层原创符文和方向饰结、中层卫星小阵与卷草、内层法术徽记；粗细区分、反向旋转、分层显现和消散。魔力弹、冲击、治疗、护盾分别使用星芒、放射、花叶和盾徽。

构图参考：[《妖精的尾巴》艾露莎施法画面](https://leviathantail.wordpress.com/character/main-characters/erza-scarlet/)、[《无职转生 II》第十五集召唤阵画面](https://jijinitchantenahome.blog.jp/archives/40580296.html)。仅观察层次、主次线宽和留白；没有将截图、纹样或标志导入工程。

原始几何预览：ARCANE_LINEWORK.svg。它不是游戏截图；实际效果由后续候选截图与录像验证。第一人称阵式放在准星右侧，限制面积与亮度，避免遮住目标。

# 海湾漫游 M5-VS3 操作

| 操作 | 按键 |
|---|---|
| 移动／驾驶 | WASD；鼠标直接环视 |
| 冲刺／加速飞行 | Shift |
| 互动／上下车 | E |
| 切换第一、第三人称 | V（步行、驾驶分别记忆） |
| 切武器 | Q／鼠标滚轮：空手 → 剑 → 魔法枪 |
| 徒手／剑／魔法枪攻击 | 鼠标左键；剑长按后松开为重击 |
| 魔法枪瞄准、装弹 | 右键、R |
| 魔法 | 1 魔力弹；2 范围冲击；3 治疗；4 护盾 |
| 起飞／平稳降落 | F |
| 飞行升降 | 空格／左 Ctrl |
| 暂停、任务追踪 | P |
| 收起／展开操作说明 | H |
| 午后／黄昏／夜晚 | T |
| 存档／读档 | F5／F9，需在地面站稳且车辆停稳 |
| 驾驶安全复位／手刹 | R／空格 |

飞行体力普通约 20 秒、加速约 10 秒耗尽；耗尽后自动缓降，不能继续上升。只在地面恢复，约 10 秒回满，至少 30% 才能再起飞。飞行时不能攻击、施法、切武器、对话、互动或保存。

魔力上限 100，停手 2 秒后每秒恢复 5。魔力弹／冲击／治疗／护盾分别消耗 15／35／30／25；冷却 1／6／10／12 秒。治疗在 3 秒内恢复 40 生命，护盾持续 5 秒并减伤一半。

桌面自动测试期间，Esc 是立即停止控制的热键。具体效果以候选实测与 STATUS 为准；此操作表不是测试通过证明。

# B 头发修正记录

原作数据已找到：两个 prefab，各 50 个 PhysBone、23 条头发链、14 个碰撞体。原始 Unity YAML 仅在本机私有目录；公开附录仅列数值及建议映射。

| 方案 | 改动 | 实际结果 |
|---|---|---|
| 1 | 两个长发节点增加上臂、前臂、手胶囊；按骨名保留躯干11/胸8.5cm | 37检查/12FAIL；跑步最大9.62cm。碰撞体启用与坐标另行核验正确 |
| 2 | 胶囊/长发半径增加余量；长发角限制90°、统一刚度.02/阻尼.4 | 37/12FAIL；30FPS跑步3.31cm，残余最大来自后短发 |
| 3 | 给后短发与侧短发补齐相同胶囊；仅跑步增加肘部极向4cm修正；试头颈朝向修正 | 37/10FAIL；30FPS步行0%，跑步8%/0.724cm，冲刺70.37%/3.362cm |

第三轮头颈朝向修正增大了枪待机/施法发梢偏移，已撤回；最终保留胶囊补齐与跑步肘部修正，继续使用R3的头颈滚转校正。此组合最终包37检查/10FAIL。三种方案已用完，不再换第四种方法。

基线来自A中间独立包：30FPS走/跑/冲刺均100%穿插，最大7.078/9.651/9.493cm；60FPS也为100%。最终报告必须使用最终包同一套测量，不能将撤回部分后的组合冒充第三轮原结果。

口径：每帧读取8个真实Kawaii头发节点、150个物理节点；头发骨骼球与固定的网格实量手臂代理胶囊比较，包含头发半径。骨骼代理不等于精确网格穿插，慢放目视独立。30/60FPS差距未支持“步长是主因”，未改插件或引擎。头发物理保持启用。裙摆、胸/腿丝带节点未改。

发梢使用每一个匹配末梢相对空手待机的横向差值，左右不会相互抵消。风力关闭、外力为0已实测；姿态与碰撞/后续约束影响尚未彻底消除，不能归因于风力。

蓝色箭头来源证据：R4截图取在武器切换后的召唤残余阶段；Buff_Cast含Arrow/BigArrow发射器，原代码在召唤和消散两个方向均触发。已改为仅装备召唤时短暂Gunshot_Cast，并立即销毁结束后的召唤组件。最终持枪待机/ADS对照中未见旧蓝箭头；全部切换状态无残留尚未完整验收。

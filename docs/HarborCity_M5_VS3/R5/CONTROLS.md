# R5 操作与移动规则（最终候选参数）

按键与视角增益沿用 R4；Q/滚轮切换、B 武器库、V 视角、P 暂停、T/H/F5/F9 不变。测试期间 Esc 立即停止桌面操作。

| 出招状态 | R5 参数 |
|---|---|
| 水平速度 ≥10 cm/s 的地面剑/拳 | UpperBody；速度倍率0.8，跑速400时320 cm/s；剑混入0.10秒，拳0.09秒 |
| 站定 <10 cm/s | 保留 FullBody；原命中窗口、伤害、连击时序不变 |
| 蓄力 | 前0.12秒快速点击宽限倍率1.0，此后0.5；重击判定仍0.55秒；松手后自然加速至0.8 |
| 空中剑/拳 | UpperBody、IgnoreRootMotion、速度倍率1.0；每次滞空最多2段；空中长按按普通攻击处理 |
| 冲刺攻击 | 地面降为跑速基础的0.8；不停止 |
| 移动施法 | UpperBody、0.65；站定保持全身 |
| 站定冲步 | 前方±45°、250cm内的新目标；总位移≤120cm，保持约140cm；无目标≤30cm；丢弃侧向/后向根位移及根旋转 |
| 出招中跳跃 | 收招可取消；命中窗口内缓冲≤0.2秒；若剩余窗口超过0.2秒则过期，不延长冻结窗口 |
| 上身朝向 | 瞄准偏角>60°时身体转向目标约0.1秒；移动输入持续生效 |

最终独立包：跑剑、冲刺剑与FP剑最低/平均320cm/s；常规跑跳剑最低400、平均399.884cm/s，FP额外上下晃动0cm。跑重击松手后加速期间最低234.133、平均317.751cm/s，不能笼统称所有出招最低320。站定重击10/10命中、前移78.667cm、横移0；完整双人入画未量测。空中规则、跳跃缓冲和施法额外专项13/0。规定横向1.2m跑拳0/10保留FAIL；近距离跳拳命中不替代该项。伤害、射程、命中窗口、魔力与冷却未调整。

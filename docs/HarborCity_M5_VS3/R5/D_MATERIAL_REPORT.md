# D 魔导枪材质

R4 压平细节的直接原因是材质混合：原贴图细节只保留9%，归一化后夹紧在0.7–1.07，主体带1.1自发光；法线未接入、粗糙度为常量。不是单凭截图推断光照分段。

R5 在私有 Blender 5.2.2 工程完成对照，游戏材质使用原 BaseColor 的均值归一化细节（强度0.5，范围0.45–1.55），保留法线及粗糙度。象牙底色225/215/195、淡金215/190/130均从sRGB转线性；金属度0.9，金属粗糙度0.3–0.45。几何、符文环及槽位未重建；新增材质属于购买素材派生资产，仅留本地加密包。

实际三次处理：
1. 材质接入：首轮独立包午后偏冷灰、傍晚武器库偏粉红，屏幕取样未通过。
2. 武器库中性白平衡与白色补光：编辑器复核仍偏粉红。
3. 只对星潮象牙的独立预览关闭世界天光、间接光和反射环境，保留预览棚灯及真实材质：粉红偏色消除，木纹/刻痕可见；主世界Lumen设置未改。

三处最终独立包截图与R4最终候选按同脚本复拍，位置和旋转逐项一致，见D_MATCHED_CAMERA.json。屏幕小区域中值：预览主体(204,204,190)、金属(188,181,161)；午后FP主体(85,97,98)、环带金属(116,110,74)，均FAIL。傍晚全身机位枪体过小，可靠取样NOT_MEASURED。首版FP取样误落青色晶核，已保留为INVALID_ROI并更正，不充当枪身数据。完整物体分割取样NOT_RUN；基色参数不代替屏幕像素，淡金亮度与造型用户PENDING。

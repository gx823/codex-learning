# M5-VS3 R1 · 门前操作

Q：空手 → 剑 → 魔导枪 → 空手。动作中按 Q 会排队；剑在右手召唤，切走时消散。

剑：左键短按三段连击；按住约 0.55 秒以上蓄力，松开重击。整身挥斩期间阻止额外行走；按住蓄力可慢走。

1 / 2：进入攻击魔法瞄准。按住左键选择目标/地面范围，移动鼠标观察，松开发射。右键或同一数字键取消，不扣魔力；不操作约 8 秒取消。

3：受伤后治疗，约 0.65 秒起手，随后 3 秒最多回复 40；满血不消耗。4：护盾，约 0.4 秒展开、持续 6 秒、减伤 50%。

魔力/冷却：魔力弹 15/1 秒；冲击 35/6 秒；治疗 30/10 秒；护盾 25/12 秒。

P 菜单新增伤害数字与命中镜头震动开关（当前会话设置；按钮实点尚未验收）。V 切视角，H 操作说明，T 时段；其余冻结玩法不变。

步行/飞行鼠标增益 1.5，驾驶 1.125，ADS 1.6/0.625 未调整。阶段门剑术录像使用测试专用侧后机位，镜头高于腰部，不代表操作系统鼠标测试。

门后最短人工复测：开阔地持剑走跑后连按三次左键、长按再松开；按 1，按住左键用真实鼠标左右切换两名目标再松开；受伤后按 3，再按 4 观察受击。第一人称挥剑和施法也需要复测。

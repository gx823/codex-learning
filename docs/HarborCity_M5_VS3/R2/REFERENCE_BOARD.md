# R2 参考板

[缩略图审阅页](review/references.html)。商店图和作者作品均非本游戏截图，只学形状、层次、节奏，不导入截图或提取资源。

- [Anime Stylized VFX · Vefects](https://www.fab.com/listings/d85dee78-9584-4b4b-a3b7-4b96de33c2b8)：学习白核、饱和边缘与短促爆发的层次。
- [Stylized VFX · Vefects](https://www.fab.com/listings/a4660915-e001-4b6b-b3ca-cec7c66740ce)：学习方向鲜明的斩击与拖尾，不使用整圈模糊贴片。
- [Combat Flipbook VFX · Vefects](https://www.fab.com/listings/e4bc9aad-83c1-4f22-9930-3407ad81f127)：学习一瞬间可读的星形爆点和速度线。
- [Niagara Examples Pack · Epic](https://www.fab.com/listings/0e188eca-4e54-4fb2-a9ed-d8b8a565e600)：学习少发射器、效果类型与轻量粒子预算。
- [Electric Red Slash · Geri](https://realtimevfx.com/t/electric-red-slash/18973)：学习收尖主形状与电火花的颜色分离。
- [Venom Slash breakdown · Geri](https://realtimevfx.com/t/venom-slash-breakdown-of-the-effect-included/18903)：学习网格轮廓、遮罩与渐变如何共同定义刀光。
- [Groundbreaking Lava Attack · Paulina](https://realtimevfx.com/t/groundbreaking-lava-attack-vfx-breakdown/17186)：学习预备、地面爆发与余韵分段；不照搬其招式。
- [Stylized Sword Slash · Aashish Bharunt](https://aashishbharunt.artstation.com/projects/kQq2Qn)：学习主网格、拖尾与独立火花的分层结构。
- [Holy and Fallen Fantasy Sword · Pundalf](https://www.fab.com/listings/6e313c8f-8d99-412c-b1a8-9b889bf6c036)：银白、淡金羽翼护手最接近主角气质。
- [Oblivionyne · Wrotzal](https://www.fab.com/listings/4deb57e9-b790-4e57-90eb-d07e35278816)：参考羽翼护手与有厚度的剑脊；改色不照搬整体外观。
- [Angel Wing Sword · belialdesign](https://www.fab.com/listings/57f46f9e-9db7-4c76-8ee2-97d375459f0e)：简洁羽翼轮廓备选；当前预览不足以确认第一人称质量。
- [Luminaciel · 金曜雑貨](https://booth.pm/ja/items/8138360)：学习圣剑召唤的亮暗节奏；模型可转换，Unity 特效需另做。
- [Magic Gem Sword · Magecraft](https://booth.pm/ja/items/6229931)：学习蓝宝石、金属镶边与剑身刻纹的比例。
- [Steampunk pistol · Haridon](https://www.fab.com/listings/a1bf10b1-31e9-47a0-9c73-451d3308012f)：长枪管、木质握把和机械核心适合改成蓝白魔导枪。
- [Inquisitor pistol · Haridon](https://www.fab.com/listings/0502d668-325a-4142-bb5f-b916add042d3)：金色花纹与厚重护件；偏短铳，需拉长枪管。
- [Pirate pistol · Haridon](https://www.fab.com/listings/d3e62384-b4e0-430f-9836-1a7dc9deb169)：海港题材轮廓备选；降低海盗装饰、保留木金配色。

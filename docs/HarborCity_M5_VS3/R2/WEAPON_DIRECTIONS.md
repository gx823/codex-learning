# 武器方向待选

[看商店图](review/references.html)。以下均未购买、未导入；商店图不是本游戏截图。

| 类别 | 方向 | 对应候选 | 选择建议 |
|---|---|---|---|
| 剑 A | 白金圣剑 | Holy and Fallen Fantasy Sword | 推荐。银白剑身、淡金护手最适合主角；需先核实模型近景和贴图规格。 |
| 剑 B | 羽翼秘银 | Oblivionyne / Angel Wing Sword | 学习羽翼轮廓，减弱黑暗装饰；后者细节规格未知，不建议直接购买。 |
| 剑 C | 光之召唤剑 | Luminaciel | 金色轻盈方向；已读作者许可中的暴力表达条件，仍需按条款做内容分级。 |
| 枪 A | 蒸汽长管魔导枪 | Steampunk pistol | 推荐。枪管、握把和晶核层次清楚，可改为象牙白、淡金、星潮蓝。 |
| 枪 B | 审判短铳 | Inquisitor pistol | 轮廓更夸张，偏神官或卫兵；需缩减厚重感。 |
| 枪 C | 港口燧发枪 | Pirate pistol | 最契合港町，魔法感需要通过材质与枪口小阵补足。 |

特效包优先候选为 Anime Stylized VFX。价格、格式和许可未确定项见 [候选清单](PURCHASE_CANDIDATES.md)。先决定造型和是否采用付费素材，再做门后武器替换；现有武器手感不变。

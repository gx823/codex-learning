# 本轮操作

- B：武器库，或从 P 暂停菜单进入。B／界面关闭按钮退出；Esc 保留给桌面自动化停止。
- 武器库：剑／远程分页；拖动模型旋转、滚轮缩放、涂装色块、“试招”、“装备”。飞行、驾驶、攻击、施法、装弹、对话和死亡时拒绝打开。
- Q／滚轮：空手 → 剑 → 当前远程武器。武器库决定两槽内容；F5/F9 保存读取装备和涂装，仍需步行站稳。
- 左键剑术：三段连击；按住蓄力、松开重击。蓄满重击发射约 8 米剑气，宽约 1.8 米；穿过敌人，每人一次，同次近战与剑气不重复伤害。
- 枪：左键射击、右键 ADS、R 装弹。1/2 选魔法目标后松开发射，3 治疗、4 护盾，其余按原规则。
- V 切视角，P 暂停，T 切时段，H 操作提示；飞行规则和体力维持原版。

步行／飞行环视增益 1.5，驾驶 1.125，ADS 放大 1.6／输入补偿 0.625。没有改系统鼠标设置或冻结的驾驶参数。其他武器数值见 ARMORY.md。
